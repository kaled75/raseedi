# رَصيدي | Raseedi — Personal Debt Manager
## تطبيق إدارة الديون الشخصية الاحترافي — Arabic RTL Desktop App

«أموالك واضحة، وديونك تحت السيطرة»

---

## 📖 نبذة عن المشروع

**رَصيدي (Raseedi)** هو تطبيق مكتبي حقيقي ومتكامل وعالي الأمان مبني باستخدام **Electron** و **React 19** و **TypeScript** و **Vite** و **Tailwind CSS** وقاعدة بيانات **SQLite** المحلية. 

صُمم التطبيق خصيصاً لإدارة وتتبع الديون الشخصية بين المستخدم وأصدقائه وأقاربه ومعارفه، مع دعم كامل للغة العربية واتجاه اليمين إلى اليسار (RTL)، ومحاذاة محاسبية دقيقة خالية من أخطاء الفاصلة العائمة (Floating-point drift)، بالإضافة إلى مركز تصدير متطور لتقارير HTML تفاعلية ومستقلة، وملفات Excel و CSV.

## ✨ الميزات الرئيسية المنفذة

### 1. الأمان والحماية المحلية
- **تسجيل دخول محلي:** قفل التطبيق بكلمة مرور يتم إعدادها عند أول تشغيل.
- **تشفير قوي:** اشتقاق كلمات المرور باستخدام خوارزمية **PBKDF2** (100,000 تكرار مع ملح Salt عشوائي 32 بايت و SHA-512).
- **قفل تلقائي ويدوي:** قفل الشاشة بعد فترة خمول قابلة للتخصيص من الإعدادات، أو بضغطة زر واحدة.
- **تلميح آمن:** إمكانية حفظ تلميح اختياري لكلمة المرور لاسترجاعها محلياً دون تخزين كلمات مرور صريحة.
- **عزل تام:** لا توجد خوادم سحابية أو مزامنة خارجية؛ كافة البيانات مخزنة في جهاز المستخدم داخل ملف SQLite مشفر ومحمي.

### 2. إدارة الديون والالتزامات
- **نوعا الدين:** 
  - **مستحق لي (إقراض):** أموال أقرضتها للآخرين وأطالبهم بها.
  - **مستحق عليّ (اقتراض):** أموال اقترضتها من الآخرين وهي في ذمتي.
- **أرقام مرجعية فريدة:** توليد تلقائي بصيغة `DBT-ME-YYYY-XXXX` أو `DBT-ON-YYYY-XXXX`.
- **حالات الدين:** (مفتوح، مسدد جزئياً، متأخر عن الاستحقاق، مسدد بالكامل، ملغي).
- **تواريخ الاستحقاق:** تنبيهات ملونة عند اقتراب موعد السداد، ووسم بارز للديون المتأخرة.
- **شريط تقدم السداد:** مؤشر رسومي يوضح نسبة ما تم سداده من أصل الدين.

### 3. نظام المدفوعات والحسابات المالية الصارم
- **منع تجاوز الرصيد (Overpayment Prevention):** النظام يرفض رفضاً قاطعاً تسجيل أي دفعة تتجاوز الرصيد المتبقي للدين.
- **منع التكرار (Debounce & Idempotency):** حماية من تكرار تسجيل الدفعات عند النقر المزدوج السريع.
- **معاملات ذرية (Atomic DB Transactions):** تحديث الرصيد، وتحديث حالة الدين، وحفظ الإيصال داخل Transaction واحدة لمنع أي تعارض.
- **إيصالات سداد احترافية:** توليد إيصال سند قبض/صرف معتمد يحمل رقماً تسلسلياً `REC-YYYY-XXXX`، ويحتوي على الرصيد قبل وبعد الدفعة، وطريقة الدفع، وحقول التوقيع، وقابل للطباعة مباشرة.
- **إلغاء موثق للدفعات:** إمكانية إلغاء الدفعات الخاطئة مع إلزام المستخدم بكتابة سبب الإلغاء لتوثيقه في سجل التدقيق المالي، مع إعادة احتساب الأرصدة تلقائياً.

### 4. إدارة الأشخاص وسجلاتهم (Contacts)
- إضافة وتعديل بيانات الأصدقاء والأقارب (الاسم، الهاتف، البريد، العنوان، الملاحظات).
- احتساب الرصيد التراكمي الحي لكل شخص:
  - إجمالي ما أطلبه منه (مستحق لي).
  - إجمالي ما يطلبه مني (مستحق له).
  - صافي الموقف المالي (Net Balance).
- **منع الحذف غير المحاسبي:** يمنع النظام حذف أي شخص مرتبط بديون سابقة، ويستبدله بـ **الأرشفة** لحفظ نزاهة السجلات المالية.
- **كشف حساب شخصي تفصيلي:** استخراج كشف حساب كامل لأي شخص يضم جميع الديون والدفعات المسددة وتواريخها وقابل للطباعة.

### 5. مركز التصدير والمشاركة
- **تصدير HTML مستقل (Self-contained):**
  - ملفات تقرير HTML كاملة تعمل بدون إنترنت وبدون أي مكتبات خارجية.
  - مظهر مخصص (فاتح مناسب للطباعة و PDF، أو داكن عصري).
  - دعم اللغتين (العربية RTL والإنجليزية LTR).
  - تحصين تام ضد هجمات حقن الأكواد (`escapeHtml` / XSS Sanitization).
  - خيارات تضمين أو استبعاد أرقام الهواتف، الملاحظات، وسجل الدفعات.
- **تصدير Excel (XLSX):** ملف مصنف إكسل احترافي يحتوي على 3 أوراق عمل مستقلة (الديون، الأشخاص، المدفوعات).
- **تصدير CSV متوافق:** ملفات CSV بترميز **UTF-8 مع BOM** حتى تفتح الأسماء العربية في Excel دون تشوه الرموز.

### 6. التقويم والتذكيرات الودية
- عرض شهري لمواعيد الاستحقاق.
- رصد وتصنيف الديون المستحقة خلال الأيام الـ 7 القادمة.
- **قوالب رسائل تذكير لطيفة:** نصوص جاهزة بأسلوب راقٍ وودي ومعدّة مسبقاً، يمكن نسخها بضغطة زر واحدة لمشاركتها عبر واتساب أو الرسائل القصيرة.

### 7. النسخ الاحتياطي والاستعادة الذاتية
- أخذ لقطة ذرية لقاعدة البيانات عبر `VACUUM INTO`.
- حساب بصمة رقمية **SHA-256** لكل ملف نسخة احتياطية لضمان سلامته من التلف.
- فحص سلامة بنية الملف والجداول قبل أي استعادة.
- **إنشاء نسخة احتياطية احترازية تلقائية** من البيانات الحالية قبل تنفيذ أي استعادة لمنع فقدان البيانات.

### 8. الإعدادات والوضع التجريبي
- تخصيص العملة (الافتراضية: الدينار الليبي `LYD`، مع إمكانية استخدام أية عملة أخرى).
- تخصيص عدد المنازل العشرية (الأقراش/الدراهم) وموضع الرمز.
- وضع الخصوصية لإخفاء الأرصدة (عرض `••••••`).
- **وضع البيانات التجريبية (Demo Mode):** إمكانية إدراج بيانات تجريبية واقعية لتجربة التطبيق، وحذفها بضغطة زر واحدة دون المساس بالسجلات الحقيقية.
- فحص سلامة قاعدة البيانات `PRAGMA integrity_check`.

## 🚀 تعليمات التشغيل والتطوير

### 1. المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو 20 أو 22).

### 2. تثبيت الحزم
من داخل مجلد المشروع:
```bash
npm install
```

### 3. تشغيل وضع التطوير
لتشغيل بيئة التطوير بالتزامن (Vite Dev Server + Electron Desktop Window):
```bash
npm run dev
```

إذا أردت تشغيل واجهة الويب فقط في المتصفح للتطوير السريع:
```bash
npm run dev:vite
```
ثم افتح: `http://localhost:5173/`

### 4. تشغيل الاختبارات وضمان الجودة
لتشغيل حزمة الاختبارات الآلية التي تفحص العمليات المالية، والتحقق من منع الدفعات الزائدة، وتكامل قاعدة البيانات:
```bash
npm test
```

### 5. بناء تطبيق سطح المكتب لنظام Windows
لتجهيز ملف تثبيت Windows احترافي بصيغة **NSIS** مع نسخة محمولة **Portable Executable**:
```bash
npm run dist
```
ستجد الملف التنفيذي النهائي داخل مجلد `release/`.
