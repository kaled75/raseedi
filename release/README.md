# دليل تثبيت وتشغيل تطبيق رَصيدي | Raseedi v1.0.0

تطبيق **رَصيدي | Raseedi** هو برنامج مكتبي احترافي لإدارة الديون والالتزامات المالية الشخصية، مصمم ومبني بالكامل وفق أحدث معايير الأداء وتجربة المستخدم مع دعم كامل للغة العربية واتجاه اليمين إلى اليسار (RTL).

## متطلبات التشغيل
- **نظام التشغيل:** Windows 10 أو Windows 11 (نواة 64 بت x64).
- **المعالج:** معالج يدعم معماريات x64 بتردد 1.5 جيجاهرتز فما فوق.
- **الذاكرة العشوائية (RAM):** 2 جيجابايت كحد أدنى (4 جيجابايت موصى بها).
- **المساحة التخزينية:** حوالي 350 ميجابايت من المساحة الفارغة.
- **بيئة التشغيل:** لا يتطلب أي برامج إضافية مثل Node.js أو أدوات تطوير؛ التطبيق مستقل تماماً ومكتمل.

## خطوات التثبيت والتشغيل

### الخيار الأول: التثبيت عبر المثبت الرسمي (موصى به)
1. انقر نقراً مزدوجاً فوق ملف `رَصيدي - Raseedi Setup 1.0.0.exe`.
2. حدد مسار التثبيت المفضل أو اترك المسار الافتراضي.
3. اختر إنشاء اختصار على سطح المكتب (Desktop Shortcut) وقائمة ابدأ (Start Menu).
4. اضغط على **تثبيت (Install)**، وسيتم تثبيت البرنامج ووضع أيقونته المخصصة ثلاثية الأبعاد تلقائياً.
5. يمكن إزالة البرنامج في أي وقت بأمان من خلال **لوحة التحكم (Control Panel) -> إضافة أو إزالة البرامج**.

### الخيار الثاني: التشغيل المحمول (Portable)
1. انسخ ملف `رَصيدي - Raseedi 1.0.0.exe` إلى أي مجلد تريده (أو حتى على وحدة فلاش USB).
2. انقر نقراً مزدوجاً لتشغيل التطبيق مباشرة.

## تنبيه أمان Windows SmartScreen
نظراً لأن هذا الإصدار تم إنشاؤه محلياً ولا يتضمن شهادة توقيع كود تجارية مدفوعة (EV Code Signing Certificate)، قد تظهر رسالة تنبيه من نظام حماية Windows Defender SmartScreen:
> *"Windows protected your PC"* / *"حمى Windows جهاز الكمبيوتر"*

- **طريقة المتابعة بأمان:**
  1. اضغط على رابط **المزيد من المعلومات (More info)**.
  2. اضغط على زر **تشغيل على أية حال (Run anyway)**.
  3. سيعمل التطبيق بكل كفاءة وأمان تام دون أي خطر على نظامك.

## مكان حفظ البيانات
- تُحفظ قاعدة بيانات SQLite بأمان دائم في المسار المخصص للمستخدم:
  `%APPDATA%\رَصيدي - Raseedi\raseedi.sqlite3`
- هذا يضمن بقاء بيانات المعاملات والديون والعملاء محفوظة وآمنة تماماً حتى عند تحديث البرنامج أو إعادة تثبيته.
